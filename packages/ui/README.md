# @papersync/ui

Shared theme and React components for PaperSync. Visual choices live in `src/theme.css` and the components that consume it.

Import `@papersync/ui/theme.css` after Tailwind CSS. Import components through their public subpaths, such as `@papersync/ui/button`, `@papersync/ui/card`, and `@papersync/ui/editorial-header`.

This package consumes no environment variables. Run `bun run check-types`, `bun run lint`, or `bun run test` to verify changes.
